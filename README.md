# Skills

Agent skills I use day to day. Written for `Claude Code`, ask your agent if it can use them as well.

## Own skills

- `/commit`- Turns file changes into commits.
- `/develop`- Builds a feature. Steps:
  - **Understand** interviews you until the feature is clear. Inspired by [Matt Pocock's grilling](https://github.com/mattpocock/skills/tree/main/skills/productivity/grilling).
  - **Plan** turns that into a plan you approve.
  - **Implement** writes the code using TDD. Inspired by [Matt Pocock's implement](https://github.com/mattpocock/skills/tree/main/skills/engineering/implement).
  - **Review** hunts for bugs in the finished change.

## Other skills I use

Not in this repo, worth having anyway.
